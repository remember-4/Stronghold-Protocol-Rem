| 干员 | 普通卡 ID | 本数 | 唯一阵营 | 卫戍协议专属特质 |
| --- | --- | --- | --- | --- |

| 丰川祥子 | chess_char_6_oblvns_a | 6 | 协防干员 emptyShip | 无 |

精锐 ID 为上述 ID 的 `_b` 版本。两人均购买 4、出售 1，三张普通卡合成精锐；共享卡池每人 5 张，仅六本可购买。随机禁用阵营仍遵循原模式规则，阵营被禁用时相关卡也会被禁用。

“无特质”指无额外的卫戍协议专属特质：`garrisonIds: []`。保留原版分支特性、天赋与技能。
默认三技能，三个技能均可在干员调配选择。普通精二 1 级 / 技能 4 级，精锐精二 60 级 / 技能 7 级；无模组、潜能与信赖额外加成。

## 数据、素材与构建

官方角色、技能和范围表已固定在 `tools/custom/operators-official.json`，数据来源为 Kengxxiao/ArknightsGameData 的国服客户端表，抓取日期 2026-10-05。
`tools/custom/operators.mjs` 接入 `tools/build-data.mjs`，完整重新生成数据时仍会保留两张卡和结城理。
资源地址加入 `docs/research/07-assets.json`，素材清单加入 `data/assets.json`；包含头像、半身像、立绘、技能图标及正反面 Spine 战斗模型。素材图片不直接提交 Git。

已有素材环境可运行：

```sh
npm run assets:custom
```

该命令只下载三名新增角色的素材并合并清单，不清除其他角色。首次安装继续使用原来的 `npm run assets`。
Render Docker 部署沿用 `FETCH_ASSETS=1`，无需 Build Command。源码提交到 master 后等待自动部署，若没有自动触发可 Manual Deploy → Deploy latest commit。

## 战斗实现及简化

新增战斗逻辑在 `server/sim/content/kits/extra6.js`，数值取当前所选技能及精锐状态的数据，不使用满专精数值。

予愿安洁莉娜：支持攻击追加法伤、起飞范围内失重、起飞干员攻击加成及阻挡时回血；一技能部署起飞，二技能起飞、吟唱、浮空 / 缚地与多目标法术攻击，三技能弹药、多目标物理攻击及额外飞行目标、对空庇护和飞行减速。
网页棋盘适配：二技能在释放范围内施加控制，不执行沿途滑翔；三技能保留备战格，不执行自动追击移动。三技能客户端移动辅助 token 不作为可部署召唤物暴露。起飞按引擎标记处理，不增加角色模型的浮空高度。

丰川祥子：支持无敌人时持续生成音符并获得攻击技力、直线追踪弹道、离开范围一秒消失、在飞音符提供穿透、范围攻速加成。一技能八个递减法伤音符，在充能满两层时自动释放；二技能初始钢琴，自动释放时切换钢琴 / 风琴；三技能每次演奏两枚物理及两枚法术音符，分别选法抗最高和防御最高的目标。
Fever 按同一玩家共享累计 450 点，伤害命中增加计数，技能释放触发 20 秒窗口；支持技能暂停计时 / 免费释放、二技能双音符、三技能窗口内致命伤不退场并在窗口结束后退场。
网页适配：音符直线追踪，不模拟随机初始角、弧形轨迹或钢琴贯穿；一技能音符同时发出，Fever 中每秒重复一次。一旦音符发出，其伤害采用发射时攻击力；普通音符未单独实现领主远程攻击倍率区分。当前卡池只有祥子一名 Ave Mujica 成员，未扩展其他成员攻击范围、保护或阵营联动。Fever 不增加独立 UI 计量条或切换 BGM。
这些是可玩的网页适配实现，并非原客户端逐帧复刻。

## GitHub 网页上传

1. 下载修改包并解压。
2. 在仓库根目录选择 Add file → Upload files。
3. 将解压后的目录与 package.json 一起拖入上传区，保持根目录路径；不要上传外层 ZIP 文件或外层文件夹。
4. 提交到 master，等待 Render 的新部署。

包内保留结城理之前的修改，包括精锐各叠 6 层及仅自身受到致命伤才切换俄耳甫斯。当前部署配置不在修改包内。
