# 拉普兰德精锐化后重新触发刷新叠层

每张普通拉普兰德在本轮持有后的第一次主动刷新，使已激活的叙拉古 +4 层。合成精锐视为重新获得：即使消耗的普通形态本轮已经触发，精锐在合成后的下一次主动刷新仍使已激活的叙拉古 +8 层，之后本轮不再重复。下回合恢复一次触发。

付费刷新和使用免费刷新次数的主动刷新都会触发，并共用同一张棋子的首次刷新计数。免费刷新不花资金；零资金仍可触发。商店自动更新、单纯重新触发刷新类特质，不算主动刷新。

普通合成生成全新精锐棋子，不继承普通形态的棋子计数；博士投影、升华等直接精锐化另算，保持原有行为。触发时叙拉古必须已激活；未激活时仍会消耗该首次刷新机会。

验证：71 项相关测试全部通过，包含普通/精锐、整备区、获得后下一次刷新、普通已触发后合成精锐、付费/免费刷新、免费次数消耗、零资金、下一回合和其他合成/经济规则。
