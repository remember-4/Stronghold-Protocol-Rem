# 联防入场倒地干员优先复活

## 修正

帮队友进入联防时，上一阶段倒地的干员通过 carryState.down 传入。原代码将它们强制退场，阿戈尔只响应 killed、埃芒加德只响应 fatal，导致两种复活都被跳过，直接进入再部署倒计时。

阿戈尔五人效果现在接受联防入场的这种强制退场事件，为本玩家的前三名首次倒地成员立即免费再部署，满血、技力按新部署重置。该次数与本次联防中后续被击倒时的阿戈尔复活共用；同一成员首次复活后再被击倒，不会再次使用阿戈尔复活。

埃芒加德分队命结之秘也接受该入场状态，为本玩家的干员立即免费再部署。它和本次联防后续致命伤害救援共用三次分队复活额度。

入场优先顺序：阿戈尔五人复活优先；若不适用、额度耗尽或没有成功复活，再尝试埃芒加德。两位协防玩家各自使用自己的盟约条件和复活次数，不共享额度。复活均在 battleStart 之前处理，不需要部署费用和等待再部署倒计时。

入场的强制退场仍不是实际被击倒，不伪造 kill 或 fatal，不额外触发不屈、克莱门莎叠层等被击倒收益。普通主动撤退不适用本次联防入场特例。

当前分队数据中，只有埃芒加德提供复活；所有此类初始分队复活均已覆盖。干员自身技能和装备效果未增加联防入场触发。
