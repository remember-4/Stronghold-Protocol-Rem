# 默认自持有满练度加成

本分支默认所有干员都满足“已持有且达到精二 60 级”的自持有条件，普通和精锐均获得攻击力、防御力、最大生命值 +10%。没有账号绑定、逐名勾选或开关；棋子的模式内等级档位保持原设置。

计算：模式中该棋子的基础属性（包括所选模组的平面属性）× 1.1，再进入既有技能、天赋、盟约、装备的计算。自持有加成不会与技能/盟约的百分比相加。
例如基础攻击 100，技能 +180%，盟约 +50%，结果为 100 × 1.1 × (1 + 1.8 + 0.5) = 363。
只直接提高干员的攻击、防御、最大生命值；不改变法抗、攻击速度、费用或其他属性，不直接给敌人、装置或召唤物增加 10%。由干员属性派生的召唤物效果仍遵循原来的继承机制。

所有 266 条普通/精锐干员记录（包括隐藏干员）都已应用。未生成具体属性的 DIY 选择入口不直接加成，选择到的实际干员自带加成。
`data/chess.json` 保存加成后的有效数值，因此调配面板、备战面板、浏览器战斗和服务器战斗保持一致。模组 `attr` 字段保存其在该模式中的有效贡献，原始官方模组快照未改动。

`tools/custom/owned-bonus.mjs` 由 `tools/build-data.mjs` 在生成干员属性后调用；新增干员的生成器也使用同一个 buildChess，所以重建时不会遗漏。记录上的 `ownedStatBonus: 0.1` 防止重复应用。同一模块切换、重新部署或新一局不会再次乘 1.1。

验证包含普通/精锐真实战斗、与技能和盟约的独立叠加、切换两种模组及不装备、重新部署和生成器重复调用。数值保存小数，显示沿用原界面的取整规则。

## 上传

下载最新完整修改包，解压后将内部目录与 package.json 上传到 GitHub 仓库根目录，提交 master 并等待 Render 自动部署。包内保留四名新增干员、模组修正与结城理规则，不覆盖 data/config.json 的倒计时设置。

按本分支要求，将 `enemy_1234_dsubrl`（深溟巢涌者）加入 `shared/enemyBans.js` 的禁用列表。随机波次不会选中它；悬赏决策不提供对应卡；已有悬赏、联防漏怪、固定波次和直接生成同样会过滤它。预览和战斗总敌人数排除该怪，避免禁用后仍等待不存在的敌人导致无法结束。
