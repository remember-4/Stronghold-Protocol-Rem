# 结城理接入说明

本修改基于 remember-4/Stronghold-Protocol-Rem 的 741b793（Update config.json）。

## 最终设定

- 五本卡，购买价格 4，出售价格 1；三张普通卡合成精锐。
- 盟约：拉特兰（lateranoShip）和不屈（indomShip）。
- 专属特质：战斗中，自身被击倒或本体与替身双向切换时，已激活的两个盟约各增加 3 层；精锐各增加 6 层。
- 未激活盟约不会获得层数。替身之间的切换不额外加层，也不会重置替身剩余时间。
- 三技能的塔纳托斯仅在自身受到致命伤害时切换俄耳甫斯；队友血量、再次开技能和非致命伤均不触发切换。
- 三个原版技能均可在干员调配选择，默认三技能。普通采用精二 1 级、技能 4 级；精锐采用精二 60 级、技能 7 级。暂不配置模组和潜能/信赖加成。

## 战斗实现

共用傀儡师 20 秒替身和项目现有 1 秒切换动画规则。人格面具增加生命、攻击力和攻击间隔；进入替身时造成停顿，正常结束时发动总攻击。当前卡池只有结城理这一个 S.E.E.S. 干员，因此总攻击以他自身为中心。

一技能：俄耳甫斯法术攻击；范围内有可治疗单位生命不高于 50% 时，改为治疗生命比例最低者。
二技能：塔纳托斯多目标法术攻击和概率恐惧，每 0.1 秒检查范围内恐惧敌人的斩杀阈值。
三技能：塔纳托斯多目标弱点伤害且可对空；自身致命伤后改为俄耳甫斯，恢复二阻挡，停止普攻，提供范围闪避与周期延迟治疗。

本项目采用自动战斗，主动进入替身使用既有技能自动触发规则。本修改按用户要求取消原版三技能的第二次主动切换，仅保留致命伤切换。总攻击的特殊过场采用项目现有本体切回动画，未实现原游戏全部过场时序；Back 素材本身缺少部分切换动画，会使用渲染器的可用动画回退。这不是逐帧完全复刻。

## 使用

将修改后的源码上传/提交到自己的 GitHub 仓库，再让 Render 部署该提交。仅点击 Deploy Latest Commit 不会读取这里的本地修改。

本地安装与启动：

```bash
npm ci
npm run setup
npm start
```

已有旧版素材时，只补结城理：

```bash
npm run assets:makoto
```

Render 从源码构建、且此前依赖完整素材下载时，可使用：

```bash
npm ci && npm run assets
```

启动命令仍为 `npm start`。角色美术在 public/assets，保持 git-ignore，不提交到 GitHub。下载脚本与资源索引会为新环境取回素材。新干员三技能需要刷新已打开页面，避免缓存旧战斗代码。

## 修改位置

- data/chess.json、data/garrisons.json、data/bonds.json：普通/精锐角色、专属特质、盟约成员。
- server/sim/content/kits/makoto.js：专属战斗机制。
- server/sim/professions.js：同步本体/替身切换事件，先更新人格面具属性再重设生命。
- server/sim/content/index.js：注册战斗实现。
- public/js/render/units.js：各形态动画映射。
- shared/loadoutRecord.js：无模组精锐的“不装备”选项与 UI 保持一致。
- tools/custom/makoto-official.json：官方角色/技能/范围源数据快照。
- tools/custom/makoto.mjs、tools/build-data.mjs：重新生成数据时保留结城理。
- docs/research/07-assets.json、data/assets.json、tools/fetch-makoto-assets.mjs：素材索引、下载、动画解析。

## 测试与限制

专属测试验证普通 +3、精锐 +6、未激活盟约不加层、击倒及切回事件、替身间切换不重复加层、一技能治疗、二技能恐惧斩杀、三技能弱点伤害/致命伤切换/治疗/闪避、残血队友不触发切换，以及总攻击。还验证角色进入商店共享池、干员调配和前后素材中的可用动画。

技能覆盖检查为 286/286，113 名可招募角色均有战斗实现。最终相关回归运行 1814 项：1809 项通过、5 项跳过、0 项失败。

完整 npm test 还包含依赖所有旧角色/音频素材的检查；本工作环境仅下载结城理素材。仓库原来的计时测试还断言 25/30/16 秒，但 741b793 的 config.json 已改为 45/60/30 秒。这些旧断言与当前仓库配置不一致。doctor 在本执行环境无法枚举系统网络接口。
